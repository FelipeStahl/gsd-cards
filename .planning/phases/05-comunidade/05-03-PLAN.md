**As a** GSD Cards user with live Claude sessions running, **I want to** be told
unobtrusively when a new version is available and choose when to install it,
**so that** I stay current without an unannounced restart killing my terminals mid-work.

Purpose: Turns the plugin backend from 05-02 into a real, testable user-facing update
affordance. Uses only mocked-plugin unit tests headless — the real signed round-trip is
Manual-Only (owned by 05-04's boundary docs).

namespace + copy, the AppShell boot check, and both mounts.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote update endpoint → tauri-plugin-updater (Rust) | The update manifest + artifact arrive from the network; the plugin (not this frontend) verifies the ed25519 signature before install |
| updater plugin → frontend | The `Update` object and progress cross into JS; a plugin failure must not break app startup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Elevation of Privilege | `installUpdateAndRelaunch` in `src/updates/check-update.ts` | high | mitigate | Signature verification is delegated to `tauri-plugin-updater` (ed25519, before any artifact is written/executed) — the frontend never fetches, verifies, or replaces a binary itself; it only requests download-and-install of a plugin-vetted `Update` (RESEARCH Don't Hand-Roll / V6) |
| T-05-05 | Denial of Service | `checkForUpdate()` boot effect | low | mitigate | Module-cached, `.catch(() => null)` never-throws wrapper — a down/404/malformed endpoint degrades to "no update" and cannot break app startup or spam the network (once per run) |
| T-05-06 | Tampering | Live PTY sessions during update install | medium | mitigate | No silent auto-relaunch: the app requires one explicit user click ("Atualizar e reiniciar") before touching any running session, since an unannounced restart would kill live `claude` terminals (UI-SPEC resolved discretion) |
</threat_model>
