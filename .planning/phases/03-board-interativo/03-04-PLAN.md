## Phase Goal (user story)

**As a** GSD developer, **I want to** trigger a phase's action from its card or the detail panel and have the app send it only when the session is idle (prefill when a permission prompt is up, block when busy), **so that** I never corrupt a session mid-task and always see which session the command targets.
