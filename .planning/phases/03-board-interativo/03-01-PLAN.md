</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk (`.planning/` phase-directory names) → renderer state | `phase.id` is derived from directory names that may originate from a cloned/shared repo — untrusted input |
| renderer → Rust PTY (`write_session`) | the injected command string crosses into a live shell/CLI behind the PTY |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

Proven at BOTH boundaries: a JS unit test (mocked reject → error surface + re-enable) AND a Rust `cargo test` (`write_session_rejects.rs`) asserting the real backend returns typed serde-serializable `PtyError::NotFound` for a missing/killed session — the code-read claim is now a pinned test |
