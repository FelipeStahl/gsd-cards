## Phase Goal (user story)

**As a** GSD developer, **I want to** press Cmd/Ctrl+K (or click a toolbar button) to fire a common `/gsd-*` command into the active session's terminal, **so that** I can drive the workflow without retyping commands or leaving the board — while the busy guard still protects a working session.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → Rust PTY (`write_session`) | toolbar/palette rows write `/gsd-*` strings into the active session's shell |
| global keyboard → app | the Cmd/Ctrl+K listener intercepts a global shortcut |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Tampering (guard bypass) | toolbar/palette injection while busy | high | mitigate | Every row uses `resolveInjection`; busy → disabled, `payload:null`, zero `writeSession` — the palette is not a guard-bypass path around the card guard |
| T-03-06 | Denial of Service (correctness) | window-level Cmd/Ctrl+K listener intercepting the shortcut when unrelated input has focus | low | mitigate | Listener mounted only while the drawer is expanded (a session is active), per UI-SPEC scoping — removed on unmount |
| T-03-02 | Denial of Service (soft, UX) | `writeSession` rejection on a toolbar/palette activation | low | mitigate | `.catch()` + `board.actions.error.injectFailed` |
</threat_model>
