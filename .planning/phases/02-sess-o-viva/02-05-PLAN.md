## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| output do terminal → navegador do SO (abrir URL) | uma URL do output não confiável do claude é aberta no navegador — nova superfície adicionada por TERM-02 |
| output do terminal → render xterm.js | sequências de escape no output continuam sendo interpretadas pelo xterm.js |

| T-02-08 | Tampering | capability de opener abrir uma URL arbitrária/maliciosa do output (capabilities/default.json) | medium | mitigate | conceder só `opener:allow-open-url` (abrir no navegador padrão do SO, que isola a navegação), nunca permissões de opener mais amplas (executar arquivo/programa); o usuário decide clicar |
| T-02-SC | Tampering | pacotes novos @tauri-apps/plugin-opener / tauri-plugin-opener | medium | mitigate | plugins oficiais do ecossistema Tauri (mesmo publisher já aprovado na Fase 1); travar versões |
