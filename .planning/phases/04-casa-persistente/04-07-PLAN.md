<objective>
TERM-04: notify the user when a session ends or needs input — OS alert plus a sidebar/rail badge. This plan consumes the exit event built in 04-02 and the awaiting classifier from Phase 3, adds the `@tauri-apps/plugin-notification` wrapper (plugin installed in 04-01), and finalizes the badge/variant visual language.

Three wirings:
1. **Exit → state:** wire `listenForSessionExit` (04-02) into a `markExited(sessionId)` action so a naturally-exited or failed-resume session flips its row to the `exited` variant — the first phase this variant is driven by a real signal rather than sitting idle.
2. **OS notifications:** `notify.ts` wraps `isPermissionGranted`/`requestPermission`/`sendNotification` behind `ensurePermission()`, `notifyAwaiting()`, `notifyExited()`, requesting permission lazily on first need and degrading SILENTLY to badge-only on denial/error (Linux daemon absence, Windows unpackaged-dev AUMID gap — 04-RESEARCH Pitfall 5 / Environment Availability). Fire `notifyExited` from `markExited` and `notifyAwaiting` on the idle→awaiting transition (reusing Phase 3's transition-gated `setActivity`).
3. **Badge:** extend `DrawerRail`'s rail badge with the priority rule (awaiting accent > exited warning > plain numeric live count) and confirm `SessionRow`'s dot reflects awaiting/exited.

The in-app badge is the durable, permission-independent primary contract; the OS toast is best-effort. No custom notification tray (04-UI-SPEC: OS-rendered only).
</objective>

## Phase Goal (user story)

**As a** GSD user running long Claude sessions, **I want to** be alerted — by an OS notification and a sidebar badge — when a session needs my input or has ended, **so that** I do not have to babysit the terminal. *(Derived from ROADMAP Phase 4 Success Criterion #5.)*

| T-04-21 | Denial of Service | Notification permission denied / no daemon / unpackaged Windows dev (no AUMID) | low | accept | notify.ts wraps every call in try/catch and no-ops; the in-app rail/row badge is the durable, permission-independent contract (04-RESEARCH Pitfall 5 / Environment Availability) — verified by the degrade-silently test |
